# Kalo Villa Siargao Website

Official website for **Kalo Villa Siargao**, a set of five private beachfront villas in Cabitoonan, General Luna, Siargao, Philippines.

**Live site:** https://kalo-web2.vercel.app

## Pages

- **Home**: introduction to the villas, highlights, and a photo tour of the property
- **Experiences**: beach villa stays, wellness retreats, and surf trips
- **Packages**: villa package details and included services
- **About**: the story behind Kalo Villa
- **Contact**: email, WhatsApp, phone, map location, and reception hours
- **Booking**: a "coming soon" page that links guests to Airbnb and WhatsApp in the meantime

## Features

- Responsive layout for desktop, tablet, and mobile
- Navigation bar that hides while scrolling down and reappears when scrolling up, with a mobile menu
- Smooth scrolling and scroll-triggered animations
- Touch and drag-friendly photo galleries
- Images served through Cloudinary for faster loading

## Built with

- HTML, CSS, and JavaScript (no frontend framework)
- GSAP and ScrollTrigger for animations
- Lenis for smooth scrolling
- Lucide for icons
- Cloudinary for image hosting
- Vercel for deployment

## Running locally

No build step is needed. Clone the repo and open `index.html` in a browser.
